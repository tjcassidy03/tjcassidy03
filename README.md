🚀 **Projects in the Fall 2024 Semester**  
This semester, I completed several cool projects, including:

- **3rd Party Spotify RESTFUL API**: Designed and implemented a RESTful API with Flask to interact with a remote database hosted on PHPMyAdmin, enabling efficient storage of user information and retrieval of key user metrics in a clean JSON format.
- **Scalable News App (Proof-Of-Concept)**: Developed a news application in Node.js, leveraging an Apache HTTP server for routing and MongoDB for data storage. The app supports three user types—anonymous viewers, logged-in readers, and authors—with distinct access permissions. Mock ads were integrated, with user interactions tracked and stored in the database, capturing details such as browser type and operating system. Built on a microservices architecture, the app separates account authentication, news handling, and ad management into discrete services.
- **Virginia Counties Broadband Access ML Analysis**:  Collaborated with a team of three to analyze broadband and public hotspot access across Virginia. After sourcing and merging datasets on demographics, income, and broadband availability, we used machine learning techniques to uncover trends. A random forest algorithm identified key features influencing public hotspot and broadband dead zones per capita, followed by a comparison of four clustering strategies to analyze the identified patterns.
